# プロジェクト概要

## 目的

個人制作の非公式応援ツール集を作成する。

最初はPKゲームを公開し、将来的には観戦支援、試合前プレビュー作成、試合後レビュー作成、初観戦ガイドなどへ拡張する。

## 現在の段階

2026-06-07時点では、PKゲーム Ver0.1 をGitHub Pagesで公開する準備段階。

## 現在の構成

- トップページ
- PKゲーム Ver0.1
- プロジェクト説明
- TODO管理
- Codex向け指示ファイル

## 将来構想

- 観戦支援ダッシュボード
- 試合前プレビュー作成
- 試合後レビュー作成

## 当面の公開方針

- GitHub Pagesで静的サイトとして公開する
- 最初はPKゲームのみ公開する
- 公開後、トップページから順次コンテンツを追加する
- 公式サイトと誤認されないように注意する
