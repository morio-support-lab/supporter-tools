# プロジェクト概要

## 目的

個人制作の非公式応援ツール集を作成する。

最初はPKゲームを公開し、将来的には観戦支援、試合前プレビュー作成、試合後レビュー作成、初観戦ガイドなどへ拡張する。

## 現在の段階

2026-06-14時点で、PKゲーム Ver0.1 をGitHub Pagesで公開済み。

公開URL：
https://morio-support-lab.github.io/supporter-tools/

現在は、PKゲーム Ver0.1 の公開確認後、Ver0.2候補の優先順位決め、およびトップページ改善の検討段階。

## 将来構想

## 当面の公開方針

- GitHub Pagesで静的サイトとして公開する
- 最初はPKゲームのみ公開する
- 公開後、トップページから順次コンテンツを追加する
- 公式サイトと誤認されないように注意する
