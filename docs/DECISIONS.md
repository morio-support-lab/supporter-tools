# 決定事項

## 2026-06-07

### GitHub Pagesから始める

最初はGitHub PagesでPKゲームを公開する。

理由：
- HTML / CSS / JavaScript だけで動作するため
- サーバー処理が不要なため
- まずは小さく公開して確認したいため

### PKゲーム単体ではなく、非公式応援ツール集として管理する

リポジトリは PKゲーム単体ではなく、supporter-tools として管理する。

理由：
- 将来、観戦支援ダッシュボードや試合前プレビュー作成などを追加するため
- PKゲームを最初の1コンテンツとして扱うため

### 1コンテンツ1フォルダで管理する

PKゲームは games/pk/ に配置する。

理由：
- 今後、ゲーム・ツール・ガイドを増やしても整理しやすくするため

### 公開対象フォルダを明確にする

GitHubに上げる対象は このリポジトリ直下 とする。

公開しないもの：
- 元の作業フォルダ
- 一時ファイル
- バックアップファイル
- 個人情報や社内情報を含むメモ

### 非公式であることを明記する

トップページ、README、各コンテンツで、個人制作の非公式サイトであることを明記する。

理由：
- 公式サイトと誤認されないようにするため
- 実在のクラブ、選手、団体との関係を明確に分けるため
