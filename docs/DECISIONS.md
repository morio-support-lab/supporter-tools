# 決定事項

## 2026-06-07

### GitHub Pagesから始める

最初はGitHub PagesでPKゲームを公開する。

理由：
- HTML / CSS / JavaScript だけで動作するため
- サーバー処理が不要なため
- まずは小さく公開して確認したいため

### PKゲーム単体ではなく、非公式応援ツール集として管理する

リポジトリは PKゲーム単体ではなく、supporter-tools として管理する。

理由：
- 将来、観戦支援ダッシュボードや試合前プレビュー作成などを追加するため
- PKゲームを最初の1コンテンツとして扱うため

### 1コンテンツ1フォルダで管理する

PKゲームは games/pk/ に配置する。

理由：
- 今後、ゲーム・ツール・ガイドを増やしても整理しやすくするため

### 公開対象フォルダを明確にする

GitHubに上げる対象は このリポジトリ直下 とする。

公開しないもの：
- 元の作業フォルダ
- 一時ファイル
- バックアップファイル
- 個人情報や社内情報を含むメモ

### 非公式であることを明記する

トップページ、README、各コンテンツで、個人制作の非公式サイトであることを明記する。

理由：
- 公式サイトと誤認されないようにするため
- 実在のクラブ、選手、団体との関係を明確に分けるため

## 2026-06-14

### GitHub Organization方式で公開する

新規GitHubアカウント作成時に本人確認・不審判定で進めにくかったため、既存アカウントでログインし、Organization「morio-support-lab」を作成して公開する方式に変更した。

公開上の管理単位：
- Organization: morio-support-lab
- Repository: supporter-tools
- 公開URL: https://morio-support-lab.github.io/supporter-tools/

理由：
- 公開URLに既存個人アカウント名を出さずに済むため
- 新規アカウント作成の制限を回避できるため
- 将来、応援ツール群をまとめて管理しやすいため

### PKゲーム Ver0.1 を公開完了とする

GitHub PagesでトップページおよびPKゲーム Ver0.1を公開した。
PCおよびスマホでトップページとPKゲーム画面が表示できることを確認済み。

今後は、効果音、ゲーム一連操作、localStorage保存内容の確認を継続しつつ、Ver0.2候補の優先順位を決める。

## 2026-07-12

### PKゲームのスマホ操作を改善

スマホで画面下までスクロールしなくても方向を選べるように、ゴール内を左・中央・右の3つのタップエリアに分けた。

操作方針：
- 攻撃時はタップしたエリアへ蹴る
- 守備時はタップしたエリアを守る
- PC向けの従来の方向ボタン操作は残す

### スマホ操作改善版をGitHub Pagesへ反映

GitHub Pagesへ反映し、公開URLでスマホ操作を含む動作を確認済みとする。

確認内容：
- ゴール内の左・中央・右のタップで攻撃方向・守備方向を選べる
- PC向けの従来ボタン操作が残っている
- トップページからPKゲームへのリンクで一時的に404が発生したが、リンク記述は正しく、キャッシュまたはGitHub Pagesの反映待ちによるものと確認した
- 反映待ちの解消後、公開URLで正常に動作することを確認した
